# co2-forecast-model
Carbon Neutrality: Modeling Global CO2 Emissions for a Net-Zero Future 
Using the ChinaTS2.mlx file, load the ChinaDataUnclean1.mat file into the workspace, this is the "cleaned" data for China's emissions (the missing values are filled)
Run the file to look at all the background information graphs and carbon emission predictions made by the ARIMA time series
